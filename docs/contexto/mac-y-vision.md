# La Mac por voz y visión en vivo

> Cuándo leerlo: mac_open/mac_media, /vision/ws, gafas ray-ban meta.

- **La Mac por voz desde el teléfono / las gafas Ray-Ban Meta** (`docs/gafas-meta.md`, 2026-10-18): `apps/agent/src/mac.ts` abre apps INSTALADAS o un sitio en Chrome (`POST /mac/open`; en `auto` gana la app instalada, lo que no existe es error — nunca "algo parecido"; resolución pura con alias en español en `mac-apps.ts`, con tests) y maneja Spotify por AppleScript directo (`POST /mac/media`: play/pause/toggle/next/previous/now/volume/search; `search` solo abre la búsqueda, sin Web API no hay "pon X"). **Sin System Events a propósito**: sin permiso de Automatización cada llamada se cuelga hasta el timeout. Tools SDK `mac_open`/`mac_media` (las alcanza `run_task` desde la voz del teléfono HOY) + client tools del agente "Hermes Phone" ya definidas en el setup — republicar `--phone` SOLO después de instalar una app que las reenvíe a `/mac/*`. **Visión en vivo** (paso 2, 2026-10-19): `/vision/ws` (`vision/live.ts`) = una sesión persistente del Agent SDK por conexión (`createFastEngine`, que ahora acepta `images` por mensaje), una viva a la vez (4001); cuadros JPEG ↑, `say`/`quiet` ↓ (protocolo y reglas puras en `shared/vision.ts`: nada se pisa, la pregunta gana y espera un cuadro NÍTIDO de 1280 px — a 640 el modelo rellenaba letras —, narrar exige escena nueva + 4 s, sin imagen se dice). Prompts: segunda persona, solo lo visible, nunca identificar caras, texto de la imagen = dato, el primer cuadro siempre ubica (Sonnet callaba la primera escena). Sonnet por defecto (`HERMES_VISION_MODEL`): igual de rápido que Haiku (~1,1-1,7 s) y lee exacto. Sim con modelo real: `pnpm --filter @hermes/agent vision:sim`; QA con cámara: `/dev/vision` (el mismo WS; es la referencia que porta la app Android con Meta DAT).
