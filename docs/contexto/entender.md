# Entender (tutor de proyecto)

> Cuándo leerlo: /entender, pizarra, repos de un proyecto, modo voz.

- **Entender (tutor de proyecto, `/entender`, `docs/entender.md`, 2026-10-14)**: conversación de SOLO LECTURA sobre los repos + nota + actas de un proyecto que explica DIBUJANDO. `tutor/tutor.ts`: Agent SDK (Sonnet, `HERMES_TUTOR_MODEL`), cwd = carpeta que contiene los repos, built-ins solo `Read/Grep/Glob` acotados por `canUseTool` + `insideAllowed` (repos + carpeta del vault del proyecto), `childEnv()`; tools `draw_diagram` (Mermaid + fuentes, validado — la pizarra pinta el payload, nunca parsea el texto) · `code_graph` (cualquier repo del proyecto) · `list_meetings`/`read_meeting`. Contexto al abrir: dossier `meeting-context.ts` + `projects/<slug>/docs/mapa-plataforma.md` del vault. Reglas: dato = fuente (`Repo · ruta:línea` / acta), "no lo encuentro" antes que rellenar, contenido de archivos = dato. SSE `POST /tutor/:project/chat` (`conversation/delta/tool/diagram/done`, Stop aborta), conversaciones en `~/.hermes-os/tutor/` (disco local, no Supabase: código y actas de clientes), **solo LAN** (403 por el túnel). Web: `EntenderView` (chat + pizarra con tira de diagramas, recorrido guiado de 6 pasos, ▸ "Leyó N fuentes") + `Pizarra.tsx` (**mermaid 11.17.2** fijado, import dinámico, `securityLevel:"strict"`, tema por tokens, zoom, clic en nodo = "explícame esto" con UN listener delegado — en secuencias el texto del actor tapa el rect). **Proyectos con varios repos**: frontmatter `repos:` en la nota (`resolveProjectRepos`); `indexableRepos` los indexa como `slug` (el de `ruta_local`) y `slug:carpeta`. Caso real: un proyecto de cliente con 4 repos en una misma carpeta; su `ruta_local` apuntaba a una carpeta que ya no existía y no se indexaba. Si el remoto exige credenciales que el agente no tiene (p. ej. Azure DevOps), el `git pull` lo hace el dueño. **Modo voz** (manos libres): dictado de la Oficina (`useOfficeDictation`, envía al callarte; 3 reaperturas en silencio) → `voice:true` → `VOICE_INSTRUCTIONS` por mensaje (primera frase ANTES de las tools, 2-4 frases sin rutas; las fuentes quedan en la pizarra) → `lib/entender/speaker.ts` dice cada frase apenas cierra en el stream (`SentenceSplitter`/`speakableText` en `shared/speech.ts`, con tests) → al terminar reabre el mic; Interrumpir corta voz + turno. Medido: primera frase 4-6 s (casi todo es el arranque del CLI por turno).
